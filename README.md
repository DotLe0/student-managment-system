# Student Management System

This project is a simple **Student Management System** built with a graphical user interface. It allows users to manage students, courses, and grades easily through an intuitive layout.

## 🚀 Features

### **Students Management**

* Add new students by first name, last name, and class level
* Remove existing students
* View all students in a neatly displayed table

### **Courses Management**

* Add new courses
* Remove courses
* Display all available courses

### **Grades Management**

* Add grades for a student in a specific course
* Remove grades
* Show all grades for a student
* Get average grade for a specific course
* Get overall student average
